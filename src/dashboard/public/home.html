How it works

From Railway deploy to online bot

Follow these steps once. After that, day-to-day server settings live in the dashboard.

1Create a Discord application/bot

Use Discord Developer Portal and enable the bot user.

2Copy token and application ID

The token stays secret. The application ID is used for the invite link.

3Paste details into setup

Open `/setup`, choose names, add Discord values, and create the dashboard password.

4Generate the invite link

The setup page creates a safe Discord invite URL without exposing the token.

5Invite the bot to your server

Grant the recommended permissions and move the bot role above managed roles.

6Run on Railway

Use Railway Postgres, a stable setup secret, and the included production start command.
