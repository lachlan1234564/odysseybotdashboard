Before you paste anything

Create your bot in Discord first

Open Discord Developer Portal in another tab, create an application, add a bot user, and copy the values below.

1. Create the application

Go to Discord Developer Portal, click New Application, then open General Information.

2. Copy the application ID

The Application ID is public enough to use in invite links. Paste it into Client/Application ID.

3. Create or reset the bot token

Open Bot, click Reset Token or copy the existing token, then paste it once below.

4. Invite the bot

After the client ID is entered, this page generates a safe invite link with bot and slash-command scopes.
