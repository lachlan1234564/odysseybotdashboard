# Embed Replies

Embeds are rich Discord messages with a color bar, title, description, images, fields, and a footer.

## Every option

- **Content above embed** — Plain text shown before the embed.
- **Title** — Bold heading at the top.
- **Title URL** — Makes the title clickable.
- **Description** — Main body text. Supports variables.
- **Color** — Left border accent color.
- **Author** — Name, URL, and icon for the author line.
- **Large image** — Bottom image inside the embed.
- **Thumbnail** — Small image in the top-right corner.
- **Footer** — Bottom line text and optional icon.
- **Timestamp** — Adds the current time to the footer.
- **Fields** — Up to 25 name/value rows, optionally inline.

## Required bot permissions

Send Messages, Embed Links.
