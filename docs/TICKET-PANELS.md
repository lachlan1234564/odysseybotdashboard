# Ticket Panels

A ticket panel is the public entry point members see. It can be a dropdown menu, a set of buttons, or a multi-panel menu.

## How to create one

1. Create at least one **Ticket type** first.
2. Go to **Ticket Studio > Panels**.
3. Fill in the title, description, and design.
4. Choose **Dropdown** or **Buttons**.
5. Select the ticket types to include.
6. Save, then post it with `/ticket-panel` or the dashboard test button.

## Multi-panel menus

Set **Panel kind** to **Multi-panel menu** and choose child panels. Members pick a child panel first, then see its ticket options.
