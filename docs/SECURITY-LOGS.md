# Security Logs

Both anti-raid and anti-nuke can send alerts and logs to dedicated channels.

## Alert channel

Where real-time notifications are sent when a threshold is triggered. Recommended: a private staff-only channel.

## Log channel

Where structured moderation actions are recorded. These are also stored in the database and appear on the Moderation dashboard page.

## Setting up

1. Create private channels for alerts and logs.
2. Give the bot Send Messages and Embed Links in those channels.
3. Select them in the Security dashboard page.
