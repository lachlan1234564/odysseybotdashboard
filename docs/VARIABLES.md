# Variables / Placeholders

Use these placeholders in messages, embeds, channel names, and reasons:

| Variable | Meaning |
|----------|---------|
| `{user}` | Mention of the command caller |
| `{username}` | The caller's Discord username |
| `{server}` | Current server name |
| `{channel}` | Mention of the current channel |
| `{text}` | Optional `/custom` text input |
| `{reason}` | Optional `/custom` reason input |
| `{target}` | Optional `/custom` target member |
| `{memberCount}` | Approximate server member count (welcome only) |
| `{createdAt}` | Member account creation date (welcome only) |
